TITLE: Neon Nature — Deer Among Flowers

DESIGN DESCRIPTION:
A single stag stands alert in a field of oversized blooms, all drawn as if made from bent glass neon tubing against a pure-black void. Every contour — the deer's antlers, ribs and legs, the petals and stems, the grass and distant hills — is a layered SVG stroke: a bright white-hot core capped by stacked colored glows (blur + drop-shadow) in magenta, cyan and lime so the tubes appear genuinely lit. A faint, blurred reflection mirrors the scene across a dark glass floor beneath, and each tube carries an almost imperceptible flicker and hum, with occasional brighter surges, so the piece feels like a real illuminated installation rather than a static illustration.

MAJOR VISUAL TECHNIQUES:
- Inline SVG line-art built entirely from stroked paths (no fills, no external assets)
- Layered glow: duplicate strokes with increasing blur/opacity + SVG <filter> Gaussian bloom and CSS text/box shadow for the phosphor halo
- White-hot inner core stroke over a saturated color stroke to mimic gas-tube luminance
- Subtle per-element flicker via staggered CSS opacity/blur animations and occasional surge keyframes
- Dark reflective floor via a vertically flipped, masked, blurred clone of the scene
- System-serif display type (Georgia) with wide-tracked labels for a gallery-plaque feel
- Reduced-motion fallback that freezes flicker/animation while keeping the glow intact

INTENDED INTERACTION MODEL:
Quiet, admiring viewing. The scene breathes and flickers on its own. Hovering the deer or a flower cluster triggers a localized brightening (the tube "warms up") and the reflection responds; the floor reflection and ambient flicker do the rest with no input required. Fully keyboard/pointer-free by default, honoring prefers-reduced-motion.
