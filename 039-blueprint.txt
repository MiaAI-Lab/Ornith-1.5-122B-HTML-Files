TITLE
-----
Drafting E-01 — A Blueprint That Builds Itself

DESIGN DESCRIPTION
------------------
A classic cyan blueprint sheet framed with corner marks and a title block, on which a residential elevation and floor plan draw themselves into existence line by line. Every wall, roof, window and dimension line is an inline SVG stroke that animates via stroke-dashoffset, so the drawing literally "builds up" from nothing — structure first, then openings, then annotations. Behind it, a canvas grid of fine and major lines breathes almost imperceptibly, with a slow travelling highlight like a drafter's eye scanning the sheet. Dimension lines in a warm amber accent carry tick marks and metric measurements, while a compass rose and a callout bubble add authentic drafting detail.

MAJOR VISUAL TECHNIQUES
-----------------------
- Inline SVG stroke-draw: paths use pathLength="1" + stroke-dasharray/offset animated to 0 so lines extend into place.
- Staggered build order via animation-delay — walls, then roof, openings, hatching, then dimension lines and notes.
- Canvas blueprint grid: minor/major line tiers with a subtle breathing offset and a slow radial "eye" highlight.
- Classic blueprint palette (cyan #1266b4 ground, white drafting lines) with a warm amber accent for dimensions and callouts.
- True drafting conventions: dimension ticks, metric labels, a rotated vertical dimension, leader line + callout bubble, compass rose, title block and sheet number.
- Corner registration marks and a double frame drawn with CSS for the authentic print feel.
- Reduced-motion fallback: all strokes resolve instantly to their finished state.

INTENDED INTERACTION MODEL
--------------------------
Presentational and self-animating — the plan draws itself once on load, like watching a drafter work. There are no controls; the experience is a looping "first-draw" that settles into a quiet, breathing stillness. Pointer/touch is not required; the piece is designed as an ambient, cinematic reveal of a technical drawing coming to life.
