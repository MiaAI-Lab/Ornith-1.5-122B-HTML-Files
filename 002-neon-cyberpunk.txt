MAJOR VISUAL TECHNIQUES:
- Perspective grid floor: a div rotated with perspective() + rotateX(~68deg), filled with crossed repeating-linear-gradients (purple vertical lines + a cyan horizontal layer via ::before with mix-blend-mode:screen) and an infinite background-position animation to simulate forward motion.
- Retro grid-sun: radial body (yellow→orange→magenta) with a ::after of horizontal dark bands using a linear-gradient mask so only the lower half shows.
- Neon glow type: stacked text-shadow layers (white core + magenta + purple halos) plus a stepped @keyframes flicker (opacity steps) for the "burning neon" effect; chrome words use a metallic linear-gradient clipped to text (background-clip:text) with a magenta drop-shadow.
- City silhouette: two inline SVG groups — a distant purple skyline and a near-black foreground skyline with individual lit windows (cyan/magenta rects) and pulsing rooftop beacons; some buildings use a stepped "lit" flicker animation.
- Scanline + rolling-scan overlay: full-screen repeating-linear-gradient stripes (multiply blend) with a translucent cyan band that rolls top→bottom.
- Retro sun halo breathing animation and a twinkling SVG star field.
- Masked marquee ticker (edge-fade mask) with duplicated content for a seamless infinite scroll.
- IntersectionObserver reveal for hero content; full prefers-reduced-motion fallback disables all motion.

INTENDED INTERACTION MODEL:
- Passive/ambient: grid floor scrolls continuously, sun halo breathes, windows/beacons flicker, scan band rolls, marquee scrolls — all CSS keyframes, no input required.
- Hover: nav links shift from muted to lit cyan with a glow text-shadow; the "Enter the Grid" solid button and "Watch Trailer" ghost button lift (translateY) and intensify their glow.
- Scroll: as hero content enters the viewport each block fades+slides up once (IntersectionObserver, threshold .12); if reduced-motion or no IO, all reveal at once.
- Click: nav "Jack In" button and CTAs are anchor/button triggers (href="#grid"/"#story") — presentational only in this demo.
- Accessibility: reduced-motion media query kills all animations and fixes the neon wordmark at full opacity.
