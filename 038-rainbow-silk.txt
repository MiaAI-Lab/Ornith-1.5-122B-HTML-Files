TITLE
-----
Iridescent Silk — A Spectrum in Motion

DESIGN DESCRIPTION
------------------
Layers of luminous, translucent bands flow across the screen like a length of rainbow silk caught mid-drift. Each layer is a stacked sine wave rendered on canvas, and the hue travels the full visible spectrum along the fabric so the surface shimmers from red through violet and back. Because the waves are drawn as filled, semi-transparent ribbons layered over one another, they slide across and through each other, producing the shifting highlights and sheen of real satin. Motion is continuous and slow — a looping, seamless undulation — so the piece feels alive but never chaotic, and the typography is set in a quiet, high-contrast serif so it never competes with the cloth.

MAJOR VISUAL TECHNIQUES
-----------------------
- Canvas-drawn, layered sine-wave ribbons: several stacked waves with differing amplitude, wavelength, speed and phase.
- Spectral iridescent gradient: a single HSL sweep (hue 0→360) mapped along each ribbon so colour flows across the fabric.
- Translucent fills (low globalAlpha) + additive-ish layering to mimic the luminous sheen of silk where folds overlap.
- A soft highlight stroke along each wave crest to sell the glossy, light-catching quality of satin.
- Seamless loop: each wave advances by exactly one wavelength per cycle so the motion never visibly restarts.
- A subtle vignette and a restrained serif caption keep the composition premium and editorial rather than noisy.
- Reduced-motion fallback: a gentle static gradient remains instead of a frozen chaotic frame.

INTENDED INTERACTION MODEL
--------------------------
Hands-off by default — the silk flows on its own in a seamless loop, meant to be admired as a living backdrop. On pointer/touch move, the cursor acts as a gentle wind: the nearest wave layers tilt and shift their phase away from the pointer, so the fabric seems to part and ripple around the hand. The effect is soft and springy, never jarring, then settles back into the idle undulation.
